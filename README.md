# SIH26162-Industrial-Fire-AI
1. Project Title : 
AI-Based Detection and Classification of Industrial Fires and Persistent Thermal Sources Using Satellite Data

2. Problem :
Industrial areas can experience fires and persistent high-temperature events. It can be difficult to quickly identify unusual thermal activity and understand its location. A simple system is needed to detect and classify such events using satellite data and present the information clearly.

3. Objectives :

Detect unusual thermal events using satellite data.
Identify possible industrial fire-related events.
Classify thermal events into different categories.
Show detected event locations on a map.
Provide simple risk/event information.
Evaluate the performance of the AI model.

4. Proposed Solution :
We propose an AI-based system that uses satellite thermal data, particularly NASA FIRMS data, to identify unusual thermal events. The system will process the data and use an AI/ML model to classify events such as industrial fires, persistent thermal sources and other thermal activity. The detected events will be displayed on a map-based dashboard using location data and OpenStreetMap.

5. Workflow :

NASA FIRMS / Satellite Data
          ↓
     Data Processing
          ↓
       AI / ML Model
          ↓
  Thermal Event Detection
          ↓
       Classification
          ↓
     Location Mapping
          ↓
   Risk/Event Information
          ↓
       Dashboard

6. Expected Outcome :
The project is expected to provide a simple system for detecting and classifying unusual thermal events and displaying their locations on a map. It will help users understand potentially important thermal events more easily and can support early monitoring and response planning. The AI model will be evaluated using suitable performance measures such as accuracy, precision, recall and F1-score.

# Dataset Notes

## Data Source
NASA FIRMS (Fire Information for Resource Management System)

## Data Type
Satellite-based thermal anomaly data.

## Important Features

- Latitude: Location of the thermal event
- Longitude: Location of the thermal event
- Brightness: Satellite brightness temperature measurement
- Confidence: Confidence level of the detected event
- FRP: Fire Radiative Power
- Acquisition Date: Date of observation
- Acquisition Time: Time of observation

## Project Use

The dataset will be analyzed to detect and classify unusual thermal events.

The data will be used for:
- Thermal event detection
- Event classification
- Location-based analysis
- AI/ML model development
